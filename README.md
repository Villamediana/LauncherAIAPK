## Luna no computador

A mesma Luna do celular, no Windows e no Linux. Instala sem senha de administrador.

**Windows** — [LunaSetup-0.3.0.exe](https://github.com/Villamediana/LauncherAIAPK/releases/download/desktop-v0.3.0/LunaSetup-0.3.0.exe) · instala só pra você, em `%LOCALAPPDATA%\Programs\Luna`.
O Windows pode avisar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo** (o instalador ainda não é assinado; isso não pede senha).
Se o computador bloquear instaladores, use a versão que roda de qualquer pasta: [Luna-0.3.0-win-portable.zip](https://github.com/Villamediana/LauncherAIAPK/releases/download/desktop-v0.3.0/Luna-0.3.0-win-portable.zip) — descompacte e abra `Luna.exe`.

**Linux** — [Luna-0.3.0-x86_64.AppImage](https://github.com/Villamediana/LauncherAIAPK/releases/download/desktop-v0.3.0/Luna-0.3.0-x86_64.AppImage) · `chmod +x` e abra; `./Luna-0.3.0-x86_64.AppImage --install` coloca no menu.

Memória, conversa e chaves ficam em `%APPDATA%\Luna` (Windows) ou `~/.local/share/luna` (Linux).
